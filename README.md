# 🎂 Birthday Website Maker

Create beautiful, personalized birthday websites in seconds!

Birthday Website Maker is a web application that lets anyone create a unique birthday website without writing a single line of code. Choose from multiple themes, add personal photos, select background music, customize the birthday message, and generate a shareable website.

### ✨ Features
- 🎨 Multiple customizable birthday themes
- 📸 Upload and display personal photos
- 🎵 Add background music
- 💌 Personalized birthday messages
- 🔗 Unique shareable birthday URLs
- 🔄 Regenerate and customize your website
- 📦 Download generated websites as ZIP files
- ☁️ Cloud storage with Supabase

### 🛠️ Built With
- Python
- FastAPI
- HTML, CSS & JavaScript
- Supabase Storage
- Render
